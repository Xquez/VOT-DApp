# Vehicle Ownership Tracker DApp (VOT‑DApp‑main)

[![Vercel Deploy](https://img.shields.io/static/v1?label=vercel&message=live&color=black)](https://vot-d-app.vercel.app/)

A **blockchain‑based DApp** that lets an admin (RTO) register vehicles and lets owners transfer and verify vehicle ownership using an Ethereum smart contract. The frontend is built with **React** and **Vite**, while the smart contract is written in **Solidity** and managed with **Hardhat**.

## Quick Start (Local Development)
### Prerequisites
- **Node.js >= 18**
- **npm** (comes with Node)
- **MetaMask** browser extension (configured for Sepolia)
- **git**

### 1. Clone the repository (your new fork)
```bash
git clone https://github.com/<NEW_ACCOUNT>/VOT-DApp-main.git
cd VOT-DApp-main
```

### 2. Install dependencies
```bash
npm install            # installs Hardhat, React, ethers, etc.
cd frontend && npm install && cd ..
```

### 3. Set up environment variables
Copy the example file and fill in your own values:
```bash
cp .env.example .env
# Edit .env – add your Alchemy/Infura Sepolia RPC URL, private key and Etherscan API key.
```

### 4. Compile & Deploy the contract to Sepolia (or local Hardhat node)
```bash
npx hardhat compile
npx hardhat run scripts/deploy.js --network sepolia   # prints contract address
```
Take note of the printed address and update `frontend/src/constants.js` (or set `VITE_CONTRACT_ADDRESS` in `.env`).

### 5. Run the frontend locally
```bash
cd frontend
npm run dev   # Vite dev server – usually http://localhost:5173
```
Open the URL, click **Connect MetaMask**, and you’re ready to register, transfer, or verify a vehicle.

## Deployment Guide
The UI is hosted on **Vercel** (the live link above). To redeploy after UI changes:
1. Push your changes to the `main` branch of the GitHub repo.
2. Vercel will automatically trigger a new build.
3. Ensure the environment variable `VITE_CONTRACT_ADDRESS` is set in the Vercel dashboard (Settings → Environment Variables).

The smart‑contract lives on Sepolia. Re‑deploy with `scripts/deploy.js` whenever you make breaking changes to the contract, then update the address in Vercel.

## Smart Contract Details
`VehicleRegistry.sol` implements:
- **Admin‑only registration** (`registerVehicle`).
- **Owner‑only transfer** (`transferOwnership`).
- **Read‑only getters** (`getVehicle`, `isRegistered`).
- **Event emission** for UI‑side notifications.
- **Simple owner count mapping** for quick stats.

The contract uses Solidity ^0.8.19 and OpenZeppelin’s `Ownable`‑style pattern without pulling the full library (kept lightweight).

## Frontend Details
- **React 18 + Vite** – fast hot‑module reloading.
- **ethers v6** – `BrowserProvider` for MetaMask integration.
- **Dark‑mode UI** – custom inline styling gives a premium glass‑morphism feel while keeping the codebase minimal.
- **Components**:
  - `RegisterVehicle.jsx` – admin can add a vehicle.
  - `TransferOwnership.jsx` – vehicle owner can transfer.
  - `VerifyVehicle.jsx` – (not shown here) reads vehicle data.
- **Status handling** – shows transaction hash with direct link to Sepolia Etherscan.

All UI strings are short and beginner‑friendly; the code is heavily commented for clarity.

## Environment Variables
Create a `.env` file (use `.env.example` as a template):
```
ALCHEMY_SEPOLIA_URL=YOUR_ALCHEMY_OR_INFURA_URL
PRIVATE_KEY=YOUR_WALLET_PRIVATE_KEY   # used only for deployment
ETHERSCAN_API_KEY=YOUR_ETHERSCAN_KEY
VITE_CONTRACT_ADDRESS=0xYourDeployedAddress   # used by the frontend
```
Never commit `.env` to the repository – it is listed in `.gitignore`.

## Moving the Repository to a New GitHub Account
1. **Delete the existing remote** (optional, for a completely clean history):
   ```bash
   git remote remove origin   # removes the old GitHub remote
   ```
2. **Re‑initialize the repo** (if you want a brand‑new history):
   ```bash
   rm -rf .git               # removes all git history (be careful!)
   git init
   git add .
   git commit -m "Initial commit – fresh VOT‑DApp project"
   ```
3. **Add the new remote and push**:
   ```bash
   git remote add origin https://github.com/<NEW_ACCOUNT>/VOT-DApp-main.git
   git branch -M main
   git push -u origin main
   ```
The repository will now appear as a fresh project under the new account with **no previous origins**.
